01 In one paragraph

What is Agent Harness for WordPress?

Agent Harness for WordPress is a local, disposable WordPress install for AI coding agents. It runs WordPress and MariaDB in Docker on loopback, exposes site abilities through the official WordPress MCP Adapter, and resets with one command. The repo wires the stack; it does not ship an MCP server or plugin of its own.

02 Architecture

Four layers, all on your machine

The agent never touches the database or the filesystem directly. Every change goes through an ability that WordPress itself registers.

03 The loop

Discover, inspect, execute

The MCP Adapter exposes three meta-tools, so the agent learns what the site can do at runtime instead of guessing ability names.

  1. Step 1 mcp-adapter-discover-abilities

    List the abilities this site exposes.

  2. Step 2 mcp-adapter-get-ability-info

    Fetch one ability's input schema before calling it.

  3. Step 3 mcp-adapter-execute-ability

    Run the ability with parameters that match the schema.

miriamschwab/rest-get and miriamschwab/rest-write bridge to any registered REST route, so most of WordPress is reachable from the same loop.

05 Quick start

From clone to connected agent

Needs Docker Compose v2, Git, and Bash.

  1. A Provision

    Clone and set up

    Builds the image, starts WordPress and MariaDB on loopback, and installs the MCP Adapter and abilities. Running it again is safe.

    bash
    git clone https://github.com/marcop135/wp-agent-harness.git
cd wp-agent-harness
./bin/setup

  2. B Connect

    Point your agent at the site

    Claude Code registers itself. Codex and Cursor take the MCP URL and Authorization header that --print shows. Trust the project when Codex asks.

    Claude Code
    ./bin/connect && claude
    Codex
    eval "$(./bin/connect --print | grep '^export ')"
codex
    Cursor: add an HTTP MCP server with the printed values
    ./bin/connect --print

  3. C Check

    Confirm every layer answers

    Health for containers, WordPress, abilities and MCP, then the test layers that need no model turns.

    bash
    ./bin/status
./bin/test --skip-claude
./bin/wp ability list

Then ask the agent to inspect the local site: version, theme, plugins.

06 FAQ

Questions before you clone

Which AI coding agents work with it?

Claude Code, Cursor, and Codex connect over HTTP MCP. Use ./bin/connect for Claude Code, or ./bin/connect --print for the MCP URL and Authorization header other clients need.

Is the WordPress site public?

No. The harness binds WordPress and MariaDB to 127.0.0.1 only. This website is the project page and does not expose the MCP endpoint.

How do you reset the local site?

Run ./bin/reset. It destroys the Docker volumes and rebuilds a clean WordPress install. ./bin/setup alone is idempotent and does not wipe content.

Does this repo ship an MCP server or plugin?

No. The MCP Adapter and MS WordPress Abilities come from upstream. This repository provides Docker Compose, provisioning, tests, docs, and curated WordPress agent skills.
